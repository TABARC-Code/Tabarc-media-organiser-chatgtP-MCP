# TABARC Media Organiser

A local-first media library organiser with a browser-based dashboard and optional MCP connections for compatible assistants and local models.

The first read-only prototype and full project documentation are being prepared on a development branch. This `main` branch is intentionally kept minimal until the initial implementation is reviewed.

For current development, see [the repository's pull requests](https://github.com/TABARC-Code/Tabarc-media-organiser-chatgtP-MCP/pulls).
